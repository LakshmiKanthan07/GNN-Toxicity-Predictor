# GNN Toxicity Predictor

## Project Overview

This repository contains the **GNN Toxicity Predictor** project developed for the *Intelligence of Biological Systems 2* course at Amrita University. The goal of the project is to predict the toxicity of natural product compounds using graph neural networks (GNN) and complementary descriptor‑based models. The repository includes datasets, preprocessing scripts, Jupyter notebooks, analysis reports, and visualisations that demonstrate model performance and exploratory data analysis.

## Datasets

The following datasets are provided in the repository:

| File | Description |
|------|-------------|
| `BBBP.csv` | Blood‑Brain Barrier Penetration dataset (binary classification). |
| `clintox.csv` | Clinical‑Trials Toxicity dataset (binary classification). |
| `coconut_csv_lite-02-2026.csv` | A lightweight version of the COCONUT natural product database. |
| `Natural_products.csv` | Curated list of natural product compounds. |
| `npass_combined.csv` | Combined NPASS (Natural Product Activity and Species Source) dataset. |
| `NPASS3.0_naturalproducts_structure.txt` | SMILES structures for NPASS 3.0 natural products. |
| `NPASS3.0_toxicity.txt` | Toxicity annotations for NPASS 3.0. |
| `sider.csv` | Side Effect Resource – drug‑side‑effect associations. |
| `t3db_multitask.csv` | Toxin and Toxin Target Database (multitask). |
| `tox21.csv` | Tox21 challenge dataset for toxicity prediction. |
| `toxins.csv` | Large collection of toxin molecules. |

Each CSV file follows a standard schema with columns for **SMILES**, **target labels**, and optional **metadata**.

## Installation

```bash
# Clone the repository
git clone <repository-url>
cd "drug toxicity prediction/for github"

# Create a clean Python environment (recommended)
python -m venv .venv
source .venv/Scripts/activate   # Windows PowerShell
# or .venv\Scripts\activate.bat for cmd

# Install dependencies
pip install -r requirements.txt
```

---

## Running the GNN Model

```bash
python -m gnn_toxicity_predictor.train \
    --data path/to/BBBP.csv \
    --epochs 100 \
    --batch-size 32 \
    --lr 0.001
```
